# 衣物洗護 / 洗標知識庫（Week 10 RAG 外部知識）
# 格式：「# DOC <doc_id> | <標題> | <類別>」開始一份文件；其後每行「<fact_id> <內容>」為一條事實。
# 內容整理自 ISO 3758 / GINETEX / ASTM D5489 / JIS L 0001 等公開洗標規範與常見洗護知識，供課程作業使用。

# DOC sym_overview | 洗標符號總覽 | 洗標符號
OV01 洗標（洗滌標示）通常縫在衣物側縫或後領，會標示纖維成分、產地與洗滌保養符號。
OV02 國際標準 ISO 3758 定義了五大類基本保養符號：水洗、漂白、乾燥、熨燙與專業紡織品護理（乾洗／濕洗）。
OV03 依 ISO 3758，符號的排列順序固定為：水洗盆、漂白三角形、乾燥方框、熨斗、專業護理圓圈。
OV04 任何保養符號上加一個「X」叉號，表示禁止該項處理，例如水盆打叉代表不可水洗。
OV05 符號內的圓點數量代表溫度等級，點越多代表允許的溫度越高，適用於水洗、烘乾與熨燙符號。
OV06 符號下方的橫線代表處理要溫和：一條線為溫和處理，兩條線為非常溫和處理。
OV07 歐洲的洗標符號由 GINETEX（國際紡織品保養標示協會）管理並註冊為商標，內容與 ISO 3758 一致。
OV08 美國採用 ASTM D5489 標準，符號大致與 ISO 相同，但允許加註文字說明，且自然乾燥符號的畫法略有不同。
OV09 日本自 2016 年 12 月起改用與 ISO 3758 對應的 JIS L 0001，舊版 JIS 的日式洗滌符號已停止使用。
OV10 台灣的紡織品保養符號標示可參考 CNS 15291，內容與 ISO 3758 相對應。
OV11 洗標上標示的是衣物「可承受的最嚴苛處理」，用比標示更溫和的方式洗滌通常是安全的。
OV12 若洗標符號與文字說明互相衝突，建議以較保守、較溫和的處理方式為準，或洽詢品牌客服。

# DOC sym_wash | 水洗符號（洗衣盆） | 洗標符號
WA01 洗衣盆（水盆）符號代表家庭水洗，盆中的數字表示最高水溫（攝氏）。
WA02 水盆內寫 30 表示最高水溫 30°C，適合深色、易褪色或較嬌貴的衣物。
WA03 水盆內寫 40 表示最高水溫 40°C，是一般日常衣物最常見的標示。
WA04 水盆內寫 60 表示最高水溫 60°C，常見於棉質床單、毛巾與白色棉製品。
WA05 水盆內寫 95 表示可耐 95°C 高溫水洗（煮洗），通常只出現在白色純棉或麻製品。
WA06 水盆內以圓點表示溫度時，1 點約 30°C、2 點約 40°C、3 點約 50°C、4 點約 60°C、5 點約 70°C、6 點約 95°C。
WA07 水盆下方有一條橫線，表示需使用溫和洗程（減少攪動與脫水力道），常見於合成纖維衣物。
WA08 水盆下方有兩條橫線，表示需使用非常溫和的洗程，例如洗衣機的羊毛或絲質專用洗程。
WA09 水盆中有一隻手的符號代表只能手洗，水溫最高 40°C，不可機洗。
WA10 手洗時應輕壓、輕搓，避免用力扭轉或搓揉，以免衣物變形或起毛球。
WA11 水盆打叉表示不可水洗，通常需送專業乾洗，或依其他專業護理符號處理。

# DOC sym_bleach | 漂白符號（三角形） | 洗標符號
BL01 三角形符號代表漂白處理，位於洗標符號的第二個位置。
BL02 空白三角形表示可使用任何漂白劑，包括含氯漂白水與氧系漂白劑。
BL03 三角形內有兩條斜線，表示只能使用氧系（非氯）漂白劑，不可使用含氯漂白水。
BL04 三角形打叉表示不可使用任何漂白劑。
BL05 舊式洗標可能在三角形內寫「CL」，代表可使用含氯漂白劑；現行 ISO 已改為空白三角形。
BL06 含氯漂白水（次氯酸鈉）漂白力強，但會使彩色衣物褪色，也會損傷羊毛、蠶絲與彈性纖維。
BL07 氧系漂白劑（如過碳酸鈉）較溫和，多數彩色衣物可用，但羊毛與蠶絲仍不建議使用。
BL08 含氯漂白水絕對不可與酸性清潔劑（如含鹽酸的浴廁清潔劑）混用，會產生有毒的氯氣。

# DOC sym_dry | 乾燥符號（方框） | 洗標符號
DR01 方框符號代表乾燥處理：方框內有圓圈代表滾筒烘乾，方框內有線條代表自然乾燥。
DR02 方框內圓圈加 1 個點，表示可低溫滾筒烘乾，排氣溫度最高約 60°C。
DR03 方框內圓圈加 2 個點，表示可一般溫度滾筒烘乾，排氣溫度最高約 80°C。
DR04 方框內圓圈打叉，表示不可滾筒烘乾，否則容易縮水或變形。
DR05 方框內有一條垂直線，表示吊掛晾乾。
DR06 方框內有兩條垂直線，表示不脫水、直接吊掛滴乾。
DR07 方框內有一條水平線，表示平放晾乾，常見於毛衣等吊掛時容易被拉長變形的衣物。
DR08 方框內有兩條水平線，表示不脫水、直接平放滴乾。
DR09 乾燥方框左上角有一條斜線，表示需在陰涼處晾乾，避免陽光直射造成褪色或纖維劣化。
DR10 美國 ASTM 標示中，方框上方有一條弧線（像信封）代表吊掛晾乾，與 ISO 的直線畫法不同。
DR11 美國 ASTM 標示中，方框內的圓圈塗滿成實心，表示烘乾時不加熱（只吹冷風）。

# DOC sym_iron | 熨燙符號（熨斗） | 洗標符號
IR01 熨斗符號代表家庭熨燙，熨斗內的圓點表示熨斗底板的最高溫度。
IR02 熨斗內 1 個點表示低溫熨燙，底板最高約 110°C，且蒸氣可能造成損傷，適用於尼龍、壓克力等合成纖維。
IR03 熨斗內 2 個點表示中溫熨燙，底板最高約 150°C，適用於羊毛、蠶絲、聚酯纖維與嫘縈。
IR04 熨斗內 3 個點表示高溫熨燙，底板最高約 200°C，適用於棉與麻。
IR05 熨斗打叉表示不可熨燙。
IR06 熨斗下方有交叉的蒸氣線（ASTM 標示）表示不可使用蒸氣熨燙。
IR07 熨燙深色或容易發亮的布料時，建議翻到反面熨，或在上方墊一塊棉布，避免出現亮光痕跡。
IR08 有印花、燙印或亮片的部位不可直接熨燙，應翻到反面以低溫處理。

# DOC sym_prof | 專業護理符號（圓圈） | 洗標符號
PR01 圓圈符號代表專業紡織品護理，由專業洗衣店處理，包括乾洗與專業濕洗。
PR02 圓圈內有 P，表示可專業乾洗，可使用四氯乙烯（PCE）以及碳氫類溶劑。
PR03 圓圈內有 F，表示可專業乾洗，但只能使用碳氫類（石油系）溶劑。
PR04 圓圈內有 W，表示可專業濕洗，由專業洗衣店以水、特殊洗劑與設備處理。
PR05 專業護理圓圈下方有一條橫線表示溫和的專業處理，兩條橫線表示非常溫和的專業處理。
PR06 圓圈打叉表示不可乾洗；圓圈內 W 打叉表示不可專業濕洗。
PR07 舊式洗標中圓圈內有 A，表示可使用所有乾洗溶劑，現行 ISO 標準已不使用此符號。
PR08 乾洗後取回的衣物建議拆掉塑膠套，放在通風處數小時，讓殘留溶劑的氣味散去。
PR09 專業護理符號主要是給洗衣店看的，一般人不需自行判斷溶劑種類，送洗時把洗標告知洗衣店即可。

# DOC fiber_cotton | 棉與麻 | 材質保養
CO01 棉是天然纖維素纖維，吸濕透氣、耐高溫，多數棉製品可機洗並以高溫熨燙。
CO02 未經防縮處理的純棉衣物第一次洗滌可能縮水約 3% 至 5%，高溫水洗與烘乾會加劇縮水。
CO03 深色棉 T 恤建議翻面、以 30°C 以下的冷水洗滌並陰乾，可減少褪色。
CO04 白色棉製品可用 60°C 熱水洗滌，並搭配氧系漂白劑維持潔白。
CO05 麻（亞麻、苧麻）吸濕快乾但容易起皺，建議洗後趁濕拉平再晾，並以高溫熨燙。
CO06 麻纖維較硬脆，同一摺痕長期反覆摺疊容易斷裂，收納時宜捲起或減少重複摺線。
CO07 棉麻衣物應避免長時間浸泡，以免褪色或產生霉味。

# DOC fiber_wool | 羊毛與喀什米爾 | 材質保養
WO01 羊毛屬於蛋白質纖維，表面有鱗片，遇到熱水加上搓揉會產生「縮絨（氈化）」而嚴重縮水，且無法復原。
WO02 羊毛衣物應使用 30°C 以下的冷水，搭配羊毛專用或中性洗劑，以手洗或洗衣機的羊毛洗程處理。
WO03 羊毛與蠶絲不可使用含酵素（蛋白酶）的洗衣精，因為蛋白酶會分解蛋白質纖維。
WO04 羊毛衣洗後應用毛巾捲壓吸水，再平放陰乾，不可吊掛，以免被拉長變形。
WO05 羊毛衣物不可滾筒烘乾，熱與翻滾會造成縮絨。
WO06 喀什米爾（山羊絨）比一般羊毛更細緻，建議手洗或乾洗，起毛球時可用毛球梳輕輕梳除。
WO07 羊毛衣不需每次穿後都洗，穿後掛在通風處讓纖維回復，可延長衣物壽命。
WO08 羊毛衣物收納前應先洗淨，並放置防蟲劑，避免衣蛾蛀蝕。
WO09 標示「可機洗羊毛（Superwash）」的羊毛經過防縮處理，可用洗衣機的羊毛洗程清洗。

# DOC fiber_silk | 蠶絲 | 材質保養
SI01 蠶絲是蛋白質纖維，光澤好但怕鹼、怕高溫、怕日曬，且濕的時候強度會降低。
SI02 蠶絲衣物建議以 30°C 以下的冷水搭配中性或絲質專用洗劑手洗，或直接送乾洗。
SI03 蠶絲不可使用含氯漂白水或含酵素的洗劑，也不建議使用氧系漂白劑。
SI04 蠶絲洗後不可用力擰乾，可用毛巾吸水後在陰涼處晾乾，避免陽光直射造成泛黃。
SI05 蠶絲熨燙應以中低溫（約 110 至 150°C）從反面熨燙，並避免噴水造成水漬。
SI06 洗蠶絲時，可在最後一次清水中加入少量白醋，有助於恢復光澤並中和殘留的鹼性。

# DOC fiber_synth | 合成纖維（聚酯、尼龍、壓克力） | 材質保養
SY01 聚酯纖維（Polyester）耐皺、快乾、不易縮水，大多可機洗，但不耐高溫熨燙。
SY02 聚酯纖維容易吸附油汙與體味，運動衣可使用運動衣專用洗劑，或在洗前先浸泡去味。
SY03 尼龍（Nylon）強韌耐磨，但遇高溫容易變形或發黃，建議冷水洗滌、低溫熨燙或不熨燙。
SY04 壓克力纖維（Acrylic）常用於仿羊毛衣物，怕熱，烘乾或高溫熨燙容易失去彈性而變形。
SY05 合成纖維互相摩擦容易起毛球，洗滌時翻面並裝入洗衣袋可減少起毛球。
SY06 合成纖維在乾燥環境容易產生靜電，使用柔軟精或在烘衣時放入烘衣紙可減少靜電。

# DOC fiber_cellulosic | 嫘縈、天絲與莫代爾（再生纖維） | 材質保養
RY01 嫘縈（Rayon、Viscose）是以木漿製成的再生纖維素纖維，觸感柔軟、垂墜性好。
RY02 嫘縈濕的時候強度很低，洗滌時容易縮水、變形，許多嫘縈衣物標示只能手洗或乾洗。
RY03 嫘縈衣物手洗時不可用力搓揉與擰乾，應輕壓去水後吊掛或平放陰乾。
RY04 天絲（Lyocell、Tencel）也是再生纖維素纖維，強度比嫘縈高，但摩擦容易產生白化（原纖化）。
RY05 天絲衣物建議翻面、裝洗衣袋、以溫和洗程洗滌，並避免烘乾。
RY06 莫代爾（Modal）手感柔軟，常見於內衣與居家服，建議以溫和洗程與冷水洗滌。

# DOC fiber_spandex | 彈性纖維、內衣與泳衣 | 材質保養
SP01 彈性纖維（Spandex、Lycra、氨綸）怕高溫與含氯漂白水，長期接觸會失去彈性。
SP02 含彈性纖維的衣物不可高溫烘乾，熱會使彈性纖維老化斷裂，讓衣物鬆垮。
SP03 胸罩建議手洗，或扣好背扣後放入專用內衣洗衣袋以溫和洗程洗滌，避免鋼圈變形。
SP04 內衣與泳衣不建議使用柔軟精，柔軟精會殘留在纖維上並影響彈性纖維。
SP05 泳衣使用後應盡快以清水沖洗，去除泳池的氯與海水鹽分，再陰乾。
SP06 蕾絲衣物應放入細網洗衣袋或手洗，避免勾紗。

# DOC fiber_down | 羽絨衣與羽絨被 | 材質保養
DN01 羽絨衣可依洗標以手洗或洗衣機溫和洗程清洗，應使用羽絨專用或中性洗劑。
DN02 羽絨衣洗滌時應拉上拉鍊、翻面，並徹底清洗乾淨，洗劑殘留會使羽絨結塊。
DN03 若洗標允許烘乾，羽絨衣可低溫滾筒烘乾，並放入 2 到 3 顆網球或烘衣球，幫助打散羽絨、恢復蓬鬆。
DN04 羽絨衣自然晾乾時需放在通風處並多次拍打，務必完全乾透，否則羽絨會發霉發臭。
DN05 部分羽絨製品不建議乾洗，因為乾洗溶劑可能去除羽毛的天然油脂而降低保暖性，應以洗標為準。
DN06 羽絨製品收納時不可長期用真空袋壓縮，以免羽絨失去蓬鬆度，應放在透氣收納袋中。

# DOC fiber_leather | 皮革與麂皮 | 材質保養
LE01 真皮衣物一般不可水洗，應送專門處理皮革的洗衣店清潔。
LE02 皮衣淋濕時應以乾布吸乾表面水分，在陰涼通風處自然風乾，不可用吹風機或日曬。
LE03 皮革應定期使用皮革保養乳補充油脂，避免乾裂。
LE04 麂皮（反毛皮）沾到灰塵時可用麂皮專用刷順著毛向輕刷，水漬可用麂皮專用橡皮擦處理。
LE05 人造皮（PU 皮）會隨時間水解剝落，應避免存放在高溫潮濕的環境。

# DOC fiber_denim | 牛仔布 | 材質保養
DE01 牛仔褲建議翻面、拉上拉鍊、扣好鈕扣，以冷水洗滌，可減少褪色與磨損。
DE02 原色牛仔布（未經水洗）第一次洗滌褪色較明顯，應單獨洗，避免染色到其他衣物。
DE03 牛仔褲不需要每次穿完都洗，減少洗滌次數可保留顏色與版型。
DE04 牛仔褲烘乾容易縮水並加速褪色，建議吊掛晾乾。
DE05 含彈性纖維的彈性牛仔褲應避免高溫，以免彈性纖維劣化而出現白色細紋。

# DOC fiber_tech | 機能衣與防水外套 | 材質保養
TE01 防水透氣外套應使用機能衣專用洗劑，不可使用柔軟精，柔軟精會堵塞防水透氣薄膜的微孔。
TE02 機能外套表面的撥水（DWR）塗層會因髒汙與磨耗而失效，清洗後若洗標允許，可低溫烘乾或低溫熨燙以恢復撥水效果。
TE03 吸濕排汗衣不可使用柔軟精，柔軟精會降低纖維的吸濕排汗功能。
TE04 刷毛衣（搖粒絨）洗滌時應翻面並裝入洗衣袋，以減少起毛球與塑膠微纖維的釋放。
TE05 機能衣物洗前應拉上所有拉鍊、黏好魔鬼氈，避免勾傷其他衣物。

# DOC towel | 毛巾與寢具 | 材質保養
TW01 毛巾不建議使用柔軟精，柔軟精會在纖維表面形成一層膜，降低吸水性。
TW02 毛巾可用 60°C 熱水洗滌以減少細菌與異味，若產生霉味可用小蘇打或氧系漂白劑浸泡。
TW03 床單與枕頭套建議每一至兩週清洗一次，以 60°C 熱水洗滌可有效去除塵蟎。
TW04 枕頭能否水洗依填充物而異：記憶枕（記憶泡棉）一般不可水洗，纖維枕多可機洗。
TW05 棉被等厚重寢具洗滌時不可超過洗衣機容量，過大的物品應送洗衣店的大型機台處理。

# DOC fabric_blend | 混紡與成分標示 | 材質保養
FB01 洗標上的成分標示以百分比列出各種纖維，例如「棉 60%、聚酯纖維 40%」。
FB02 混紡衣物應依其中最嬌貴的纖維選擇洗滌方式，例如含羊毛的混紡應以羊毛的方式處理。
FB03 成分中即使只含 5% 左右的彈性纖維，即使主成分是棉，也應避免高溫烘乾。
FB04 棉與聚酯纖維混紡（T/C）兼具吸濕與耐皺，通常可機洗並以中溫熨燙。
FB05 台灣《商品標示法》與紡織品標示相關規定要求標示纖維成分、產地與洗燙處理方式等資訊。

# DOC special_items | 特殊衣物與配件 | 材質保養
SX01 西裝外套通常標示只能乾洗，平時穿後以衣刷刷除灰塵並掛在寬肩衣架上即可，不需頻繁送洗。
SX02 領帶多為蠶絲材質，不建議水洗，沾到汙漬應交給專業洗衣店處理。
SX03 棒球帽不建議放入洗衣機，可用軟刷沾中性洗劑局部刷洗，再套在圓形物上晾乾以保持形狀。
SX04 有亮片、珠飾或刺繡的衣物應翻面裝入洗衣袋手洗或溫和洗，不可烘乾，也不可直接熨燙。
SX05 布鞋與帆布鞋可用軟刷沾中性洗劑刷洗，晾乾時塞入白紙吸水並避免曝曬，以免開膠或泛黃。
SX06 嬰兒衣物建議與大人衣物分開洗，使用低刺激、無香精的洗劑，並徹底清洗避免洗劑殘留。
SX07 天鵝絨與燈芯絨等絨布應翻面洗滌，熨燙時應從反面以蒸氣懸空處理，以免壓扁絨毛。

# DOC stain_basic | 去漬基本原則 | 去漬
SB01 汙漬越早處理越容易去除，應先用紙巾吸起多餘的汙漬，不要來回用力擦拭以免擴散。
SB02 去漬時應從汙漬外圍往中心處理，並在布料背面墊一條乾淨毛巾吸收汙漬。
SB03 使用去漬劑前應先在衣物內側不顯眼處測試，確認不會褪色或損傷布料。
SB04 蛋白質類汙漬（血、蛋、牛奶、汗）應用冷水處理，熱水會使蛋白質凝固而更難去除。
SB05 油性汙漬應先用洗碗精或去油劑處理，再依洗標正常洗滌。
SB06 在確認汙漬完全去除前，不要把衣物放入烘衣機或熨燙，高溫會讓汙漬固著。
SB07 羊毛、蠶絲等嬌貴材質或標示不可水洗的衣物，遇到難處理的汙漬時建議交給專業洗衣店。

# DOC stain_food | 食物與飲料汙漬 | 去漬
SF01 咖啡或茶漬應盡快以冷水從背面沖洗，再以洗衣精輕搓；殘留的黃漬可用氧系漂白劑浸泡（若洗標允許）。
SF02 紅酒漬應先用紙巾吸乾，再撒鹽或小蘇打吸附，之後以冷水沖洗並用洗衣精處理。
SF03 醬油漬應先用冷水沖洗，再以洗衣精或少量白醋搓洗。
SF04 咖哩漬含薑黃色素，應先用洗碗精去除油分再以洗衣精洗滌；洗後在陽光下曝曬有助於薑黃色素褪色。
SF05 番茄醬漬應先刮除多餘醬料，以冷水從背面沖洗，再用洗衣精處理，避免使用熱水。
SF06 巧克力漬同時含有油脂與蛋白質，應先刮除，再用冷水與洗碗精處理。
SF07 牛奶漬屬於蛋白質汙漬，應以冷水沖洗後再用含酵素的洗衣精洗滌（羊毛、蠶絲除外）。
SF08 果汁漬應盡快以冷水沖洗，殘留的色素可用氧系漂白劑處理。
SF09 食用油漬可先撒上太白粉或爽身粉吸油，靜置後刷除，再用洗碗精處理。

# DOC stain_body | 身體與生活汙漬 | 去漬
ST01 血漬必須用冷水處理，可用冷水加少量鹽或含酵素洗劑浸泡，切勿使用熱水。
ST02 白色衣物腋下的汗黃漬，可用小蘇打加水調成糊狀塗抹，或以溫水加氧系漂白劑浸泡。
ST03 衣領與袖口的皮脂汙垢，可在洗前塗抹洗碗精或衣領專用清潔劑並輕刷。
ST04 口紅漬含油脂與色素，可先用卸妝油或洗碗精溶解，再用洗衣精洗滌。
ST05 粉底液汙漬可先用卸妝液或洗碗精處理，再正常洗滌。
ST06 原子筆油墨可用藥用酒精以棉花點壓溶解，再用洗衣精洗淨。
ST07 口香糖黏在衣物上時，可用冰塊冷凍使其變硬，再用鈍器刮除。
ST08 泥土汙漬應等泥巴乾燥後先拍打刷除，再以洗衣精搓洗，濕泥直接搓會擴散。
ST09 草漬可用含酵素的洗衣精或酒精處理後再洗滌。
ST10 霉斑可先在陽光下曝曬並刷除表面黴菌，白色棉質衣物可用氧系漂白劑浸泡；嚴重的霉斑可能無法完全去除。
ST11 鐵鏽漬可用檸檬汁或白醋加鹽塗抹後靜置再沖洗；嬌貴材質請交給專業處理。
ST12 蠟筆或蠟油應先刮除表面，再墊上吸油紙以低溫熨斗加熱，讓蠟被紙吸走。

# DOC machine | 洗衣機使用技巧 | 洗滌技巧
MA01 洗衣前應依顏色分類，白色、淺色與深色分開洗，新衣物第一次洗時建議單獨洗。
MA02 洗衣前應清空口袋、拉上拉鍊、扣好掛鉤，並解開襯衫鈕扣，以減少變形與磨損。
MA03 洗衣機每次放入的衣物量以洗衣槽的七到八分滿為宜，放太滿會洗不乾淨。
MA04 洗劑用量應依包裝標示與衣物量調整，過量的洗劑不會更乾淨，反而容易殘留。
MA05 嬌貴衣物、內衣與有裝飾的衣物應裝入洗衣袋，避免勾紗與變形。
MA06 洗衣槽約每 1 到 2 個月應清潔一次，可使用洗衣槽專用清潔劑或依洗衣機說明進行槽洗。
MA07 洗完的衣物應盡快取出晾曬，長時間悶在洗衣機內會產生霉味。
MA08 滾筒洗衣機應使用低泡沫的滾筒專用洗劑，泡沫過多會影響洗淨與排水。
MA09 中性洗劑（pH 約 6 至 8）較溫和，適合羊毛、蠶絲等嬌貴衣物；一般洗衣精多為弱鹼性，去汙力較強。
MA10 柔軟精應在最後一次清洗時加入，不可與洗衣精混合後直接倒在衣物上。
MA11 有印花或燙印圖案的衣物應翻面洗滌，避免圖案龜裂剝落。

# DOC dry_store | 晾曬與收納 | 晾曬收納
DS01 深色與鮮豔衣物應翻面晾曬並避免陽光直射，以減少褪色。
DS02 毛衣與針織衫應平放晾乾，吊掛會使衣物因水的重量而被拉長變形。
DS03 襯衫洗後可趁濕拉平領子與袖口，用衣架吊掛晾乾，可減少熨燙的需求。
DS04 晾衣時衣物之間應保留間距，以加快乾燥並減少霉味；室內晾衣可搭配除濕機或電風扇。
DS05 換季收納前衣物必須先洗淨並完全乾燥，殘留的汗漬與皮脂會在收納期間氧化成黃斑並吸引蛀蟲。
DS06 樟腦丸與其他類型的防蟲劑不可混用，可能發生化學反應使衣物變色。
DS07 衣櫃內可放置除濕劑並定期更換，在台灣潮濕的氣候下可避免衣物發霉。
DS08 針織衣物收納時應摺疊放置，避免長期吊掛使肩膀處產生凸起變形。
DS09 洗衣店的塑膠防塵套不適合長期收納，應改用透氣的布製防塵套。

# DOC trouble | 常見洗滌問題 | 疑難排解
TR01 衣物縮水的主要原因是高溫（熱水洗、烘乾）與機械搓揉，棉、羊毛與嫘縈最容易縮水。
TR02 羊毛衣輕微縮水時，可浸泡在加了護髮乳或嬰兒洗髮精的溫水中，讓纖維放鬆後輕輕拉回形狀再平放晾乾；嚴重氈化則無法復原。
TR03 起毛球是纖維受摩擦後糾結成球，可用除毛球機或毛球梳去除，洗滌時翻面並裝洗衣袋可預防。
TR04 衣物褪色多因高溫、日曬、過量洗劑或含氯漂白，深色衣物應冷水洗、翻面並陰乾。
TR05 白衣被其他衣物染色時，應在衣物乾燥前盡快以去染色劑或氧系漂白劑處理，烘乾後會更難去除。
TR06 衣物洗後仍有異味，常見原因是洗衣槽髒汙、衣物晾乾太慢或洗劑殘留，可清潔洗衣槽並縮短晾乾時間。
TR07 洗後衣物出現白色粉末殘留，可能是洗衣粉未完全溶解或洗劑過量，可減少用量並多清洗一次。
TR08 洗後衣物變硬可能是水質硬或洗劑殘留，可在最後清洗時加入少量白醋或柔軟精（毛巾與機能衣除外）。

# DOC eco | 環保與省能洗衣 | 洗滌技巧
EC01 降低洗滌水溫可大幅節省洗衣耗能，多數日常髒汙以 30°C 至 40°C 洗滌即可洗淨。
EC02 集滿一整槽再洗、選擇適當的洗程，可節省水電。
EC03 合成纖維衣物洗滌時會釋放塑膠微纖維，使用專用洗衣袋或過濾器可減少微塑膠排放。
EC04 自然晾乾比滾筒烘乾更省電，也可減少衣物縮水與磨損。
EC05 減少不必要的洗滌次數（例如牛仔褲、外套與羊毛衣），可延長衣物壽命並減少環境負擔。

# DOC label_photo | 洗標拍攝指南 | 洗標辨識系統
LP01 拍攝洗標時應將洗標攤平，讓所有符號完整入鏡，不要只拍局部。
LP02 拍攝時應保持光線充足並避免閃光燈直射造成反光；緞面洗標特別容易反光，可稍微傾斜角度拍攝。
LP03 拍照前應先對焦，確認符號邊緣清晰不模糊，手會晃動時可將手靠在桌面上拍攝。
LP04 洗標應盡量正對鏡頭拍攝，傾斜角度過大會使符號變形而影響辨識。
LP05 洗標若有多片或正反兩面，應每一面分別拍攝。
LP06 洗標符號褪色、磨損或被剪掉時，系統可能無法正確辨識，建議改為人工確認或參考品牌官網的保養說明。

# DOC label_system | 洗標辨識系統說明 | 洗標辨識系統
LS01 本系統的洗標辨識流程分兩階段：先以 YOLO 物件偵測模型找出並切割洗標上的每一個符號，再以 ResNet 分類模型判斷每個符號的類別。
LS02 辨識結果會依 ISO 3758 的五大類（水洗、漂白、乾燥、熨燙、專業護理）整理成洗滌建議。
LS03 當照片模糊、反光或拍到的不是洗標時，系統會請使用者重新拍攝，而不會強行辨識。
LS04 系統目前的符號分類準確率約六到七成，因此對低信心的結果會提示使用者確認，必要時轉由人工客服處理。
LS05 系統只回答衣物洗護與洗標相關的問題，與洗標無關的問題會被婉拒。
LS06 系統的回答會附上引用的知識庫段落編號，方便使用者查證來源。
